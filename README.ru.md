## 🚀 Быстрый старт

```bash
# 1. Клонируем
git clone https://github.com/armadgarsone2/counter.git
cd counter/server

# 2. Права на исполнение
chmod +x srcds_run bin/*

# 3. ⚠️ Смени пароль RCON (в файле стоит CHANGE_ME)
nano cstrike/cfg/server.cfg

# 4. Запуск
./srcds_run -game cstrike +map de_dust2 -maxplayers 32 -port 27015 +tickrate 100

# 5. (По желанию) как сервис
sudo cp ../tools/css34.service /etc/systemd/system/
sudo systemctl enable --now css34
```

**FastDL:** файлы раздаёт nginx, чтобы игроки качали модели на полной скорости:

```
sv_downloadurl "http://YOUR_SERVER_IP/cstrike/"
```

## ⚙️ Под капотом (для технарей)

- Этот старый билд стабильно запускает только плагины, собранные **SourceMod 1.9**; 1.12 не загружается, 1.10 роняет сервер. Золотое правило.
- У таблицы загрузок есть потолок: переполнишь — реальные клиенты крашатся при подключении. Держи список точным и лёгким.
- Пути материалов из .mdl разрешай **без учёта регистра**; Linux к регистру строг, а цена ошибки — фиолетовые игроки.
- Сырой персидский текст в этом движке рендерится битым — пиши по-английски или сначала делай reshape.
- Все военные истории целиком — в `skills/`.
