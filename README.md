## 🚀 راه‌اندازی سریع

```bash
# 1. کلون
git clone https://github.com/armadgarsone2/counter.git
cd counter/server

# 2. دسترسی اجرا
chmod +x srcds_run bin/*

# 3. ⚠️ پسورد RCON رو عوض کن (توی فایل الان CHANGE_ME ـه)
nano cstrike/cfg/server.cfg

# 4. اجرا
./srcds_run -game cstrike +map de_dust2 -maxplayers 32 -port 27015 +tickrate 100

# 5. (اختیاری) سرویس دائمی
sudo cp ../tools/css34.service /etc/systemd/system/
sudo systemctl enable --now css34
```

**FastDL:** فایل‌ها با nginx سرو می‌شن تا پلیرها مدل‌ها رو با سرعت کامل بگیرن:

```
sv_downloadurl "http://YOUR_SERVER_IP/cstrike/"
```

> ⚠️ فایل‌های FastDL باید پرمیشن خوندن عمومی (644/755) داشته باشن وگرنه nginx ارور 404 می‌ده و پلیرها می‌افتن رو دانلود کند مستقیم.

## ⚙️ زیر کاپوت (برای اهل فن)

- درخت سرور **SourceMod 1.7.3** ـه؛ پلاگین‌ها با spcomp همون درخت کامپایل می‌شن (استایل transitional — پراگمای `newdecls` کنار sdktools خطا می‌ده). چند پلاگین خاص (Modes و Damage Info) با تول‌چین **1.9** کامپایل شدن.
- این بیلد **No-Steam** احراز هویت استیم رو کامل نمی‌کنه (STEAM_ID_PENDING) و `OnClientPostAdminCheck` هیچ‌وقت فایر نمی‌شه — ادمین، VIP و رنک رو باید رو `OnClientPutInServer` بایند کنی.
- `config` دیرهنگام اجرا می‌شه: `exec` ته server.cfg بعد از خط‌های خودش اجرا می‌شه — مقادیر فایل‌های exec‌شده برنده‌ان. هر cvar سمجی رو تو همه‌ی لایه‌ها چک کن.
- جدول دانلود (Downloads Table) سقف داره: زیادی پرش کنی کلاینت موقع اتصال کرش می‌کنه. لیست دقیق و حساب‌شده نگهش دار. فایل هم‌نام رو عوض نکن — کلاینت نسخه‌ی کش‌شده رو نگه می‌داره؛ مسیر/اسم جدید بده.
- متن فارسی خام تو انجین به‌هم‌ریخته رندر می‌شه — یا انگلیسی بنویس یا با reshaper درستش کن (presentation forms).
- جزئیات کامل همه‌ی این تجربه‌ها توی `skills/` هست.
