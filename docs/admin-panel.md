# راهنمای پنل ادمین (`!admin`)

پنل ادمین با دستور `!admin` یا `/admin` در چت باز می‌شود — **فقط برای ادمین‌ها**.

## منوی اصلی

```
1. دستورات پلیرها
2. دستورات سرور
3. دستورات رای‌گیری
4. مدیریت بات‌ها
5. سوپر ادمین
7. تلپورت منو
8. تنظیمات خاص
```

## ۱. دستورات پلیرها

- **کیک پلیر** — انتخاب از لیست آنلاین‌ها
- **بن پلیر** — بن ۳۰ دقیقه‌ای + کیک
- **میوت کردن** — زیرمنو: میوت (ویس) / گگ (چت) / سایلنت (هر دو)
- **چنج تیم** — جابه‌جایی بین T و CT
- **اکسچنج پلیر** — دو مرحله‌ای: اول یک پلیر، بعد فقط از تیم مقابل؛ تیمشان عوض می‌شود
- **رفع میوت/گگ/سایلنت** — فقط پلیرهای محدودشده را نشان می‌دهد

## ۲. دستورات سرور

- **چوز مپ** — لیست مپ‌ها از `mapcycle.txt`؛ با انتخاب، `changelevel` فوری اجرا می‌شود
- **بلانس تیم** — تعداد T و CT را برابر (یا با اختلاف حداکثر یک) می‌کند
- **ری‌استارت گیم** — `mp_restartgame 1`
- **سواپ تیم** — همه‌ی Tها و CTها با هم جابه‌جا می‌شوند

## ۴. مدیریت بات‌ها

- **اد بات**: رندوم / CT / T
- **سلاح بات‌ها**: همه / فقط چاقو / فقط پیستول / فقط اسنایپر
- **سطح بات‌ها**: ایزی / نرمال / هارد / اکسپرت
- **حذف بات خاص** / **حذف تمام بات‌ها** / **کشتن تمام بات‌ها**

## ۵. سوپر ادمین

یک پلیر انتخاب می‌کنید — فقط همان پلیر می‌تواند با `/cheat` منوی چیت را باز کند. دسترسی با خروج از سرور باطل می‌شود.

## ۷. تلپورت منو

- **سیو لوکیشن** — نقطه‌ی فعلی شما ذخیره می‌شود
- **تلپورت به سیو لوکیشن** — همه / بات‌ها / زنده‌ها / یک پلیر خاص
- **تلپورت پلیر به پلیر** — دو مرحله‌ای: اول مبدا (همه/بات‌ها/زنده‌ها/یک نفر)، بعد مقصد

## ۸. تنظیمات خاص

- **AllTalk** — تاگل (صحبت بین دو تیم)
- **فرندلی فایر** — تاگل
- **فریز تایم** — تاگل بین «زمان بازی بی‌نهایت» و «محدود»
- **بورن پلیر** — آتش زدن یک پلیر
- **پلیر دد** — کشتن همه یا یک نفر
- **جایگزینی سلاح همه** — ۲۵ سلاح؛ سلاح همه‌ی پلیرها عوض می‌شود
- **ری‌اسپاون پلیر** — فقط مرده‌ها، دقیقاً سر جای مرگشان
- **ست HP** — ۱۰۰ تا ۵۰۰۰ برای همه
- **آن‌بورن** — خاموش کردن آتش پلیرهای در حال سوختن
