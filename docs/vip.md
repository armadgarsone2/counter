# سیستم VIP

## فلگ دسترسی

VIP با فلگ SourceMod برابر **`o`** کار می‌کند (`ADMFLAG_CUSTOM1`).

دادن VIP به یک پلیر در `server/cstrike/addons/sourcemod/configs/admins_simple.ini`:
```
"STEAM_0:1:12345678" "o"
```

## قابلیت‌ها (پلاگین VIP Perks)

| دستور | قابلیت | توضیح |
|---|---|---|
| `!vn` | ناکلیپ | پرواز از میان دیوارها (تاگل) |
| `!vg` | گادمد | ضدضربه شدن (تاگل) |
| `!vw` | وال‌هک | دیدن پلیرها از پشت دیوار (تاگل) |

هر سه فقط روی خود پلیر اثر می‌کنند (self-only).

## فروش

- فروش VIP در حال حاضر **دستی** انجام می‌شود (ربات فروش غیرفعال است).
- برای خرید، پلیر باید به ادمین سرور پیام بدهد (متن‌های داخل بازی همین را می‌گویند).
- بعد از پرداخت، ادمین فلگ `o` را برای SteamID خریدار ثبت می‌کند و سرور را ریلود می‌کند (`sm_reloadadmins`).

## تگ چت

پلیرهای VIP در چت تگ `[VIP]` دارند (پلاگین `vip_chat_tag`).
