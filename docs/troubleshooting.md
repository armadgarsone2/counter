# عیب‌یابی

## پلاگین لود نمی‌شود

```bash
# داخل کنسول سرور:
sm plugins list
sm plugins reload <name>
```
لاگ خطاها: `server/cstrike/addons/sourcemod/logs/errors_*.log`

خطاهای رایج:
- نسخه‌ی SourceMod با پلاگین سازگار نیست → با `./spcomp` نسخه‌ی 1.7.3 دوباره کامپایل کنید.
- فایل `.smx` خراب دانلود شده → دوباره از `scripting/` کامپایل کنید.

## اسکین/صدا برای پلیر دانلود نمی‌شود

1. `sv_downloadurl` را در `server.cfg` چک کنید (باید با `/` تمام شود).
2. با `curl -I` از بیرون تست کنید که nginx فایل را با 200 می‌دهد.
3. ساختار پوشه‌ای داخل FastDL باید دقیقاً مثل `cstrike` باشد.

## سرور در لیست بازی دیده نمی‌شود

- پورت **27015/UDP** باید روی فایروال باز باشد.
- `sv_lan 0` باشد (پیش‌فرض همین است).

## مصرف ۱۰۰٪ CPU بعد از اجرا

- در این بیلد قدیمی، `autoexec.cfg` می‌تواند لوپ پردازنده ایجاد کند — از آن استفاده نکنید.
- `fps_max` را روی مقدار معقول (مثلاً 600) بگذارید.

## RCON کار نمی‌کند

- `rcon_password` را در `server.cfg` ست کنید و سرور را ری‌استارت کنید.
- از ابزار RCON با IP، پورت و همین پسورد وصل شوید.

## مپ عوض نمی‌شود

- نام مپ باید در `mapcycle.txt` باشد و فایل `.bsp` در `cstrike/maps/` موجود باشد.
